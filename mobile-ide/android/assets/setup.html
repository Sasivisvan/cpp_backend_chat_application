Pocket IDE

Code, terminals and Claude Code on your phone, plus an AI that can control the phone.

1 · Install Termux apps

Pocket IDE runs Linux, Node and Claude Code inside Termux. Install Termux and Termux:API from F-Droid. Both must come from F-Droid; the Play Store version won't work together.

2 · Allow phone access

Open Termux:API settings and allow Location → Allow all the time and Notifications, so Claude can set location reminders and alerts.

3 · One-time setup in Termux

Copy this command, then paste it in Termux and press Enter. It takes about 5–15 minutes and roughly 1.5 GB, and installs Ubuntu, Node and Claude Code.

Something went wrong?

If Termux shows CANNOT LINK EXECUTABLE … cannot locate symbol (for curl, node, …), its packages are half-upgraded. Tap Repair Termux, wait for “Done”, then do step 3 again.

Manual fixes

Repair packages:

apt update && apt full-upgrade -y -o Dpkg::Options::=--force-confnew

If that fails with an SSL/download error:

apt install -y openssl

If the mirror is down:

termux-change-repo

Check:

curl --version | head -1 && node -v

See why the IDE didn't start:

pocket-ide

4 · Let this app start Termux

Grant the “Run commands in Termux environment” permission so the Start button works.

Updates

New versions are published on GitHub automatically. The app checks on launch, or you can check now.
